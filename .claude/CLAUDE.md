# Project Memory

Instructions here apply to this project and are shared with team members.

## Context

You are a senior software engineer and product engineer.

Build a production-quality web application, not a simple HTML/CSS/JS project.

Goal:

Create a cute, funny, interactive website that feels like a polished consumer web app.

Purpose:

This website is designed to make someone smile and feel impressed through creativity and effort, NOT to be a confession website.

Tech Stack Requirements:

* Next.js (App Router)
* TypeScript
* Tailwind CSS
* Framer Motion for animations
* Component-based architecture
* Responsive mobile-first design
* Clean folder structure
* Reusable components
* Maintainable and scalable code
* Good naming conventions
* Proper separation of UI / logic / data
* Avoid monolithic files

Design Style:

* Cute
* Playful
* Soft modern UI
* Slightly romantic but not obvious
* Funny and self-aware
* Premium feel like a real startup landing page

Color palette:

* Soft pink
* Warm white
* Light pastel tones
* Rounded corners
* Glassmorphism where appropriate
* Smooth transitions

Website Flow:

1. Loading Screen

Show fake loading states like:

"Initializing cringe..."

"Loading friendship database..."

"Preparing unnecessary project..."

Use animated progress indicators.

2. Welcome Screen

Display:

"Welcome to the most unnecessary project I have ever built."

Button:

Start

3. Friendship Wrapped Section

Create multiple slides/cards.

Examples:

* Days known each other
* Who texts first more
* Most random conversation
* Biggest yapper award
* Friendship score

Add animated counters.

Add swipe / next interactions.

Make stats visually interesting.

4. Quiz Section

Create interactive quiz:

Examples:

* What am I probably doing at 2 AM?
* Favorite food?
* Biggest habit?
* Which one sounds most like me?

Requirements:

* Funny incorrect responses
* Small animations
* Score tracking
* Progress bar
* Achievement unlocks

5. Achievement System

Examples:

"Achievement Unlocked"

"Survived My Questions"

"Professional Yapper"

"Touch Grass Certified"

Create card animations.

6. Ending Section

Tone:

Cute.

Light.

Not a confession.

Example vibe:

"Building this took way too much time 😭"

"But talking with you has been pretty nice."

"See you in the next update."

7. Extra Features

* Confetti
* Sound toggle
* Local storage for progress
* Mobile optimized
* Smooth page transitions
* Micro interactions
* Hidden easter eggs
* Accessibility considerations

Code Requirements:

* Explain folder structure
* Explain architecture decisions
* Use reusable hooks where appropriate
* Avoid duplicated code
* Use TypeScript types properly
* Write clean code like a real engineering team would review it
* Use comments only where necessary
* Prioritize readability

Output Requirements:

Build this feature by feature.

Explain what files are created.

Generate code incrementally.

Do not create everything inside one file.

Treat this like a real startup-grade frontend project.
